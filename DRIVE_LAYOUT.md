# Drive Layout Conventions

| Folder | What belongs here |
|--------|-------------------|
| **Daily Intelligence** | DC reports, source ledgers, Top 10, catalog comparisons, Sunday analytics, handoff manifests |
| **REBOOTv2 production** | Psychology + System Glitch completed scripts, narration plans, captions, production assets, QA records |
| **Harvest** | Consolidated review packages ready for you to inspect |
| **Hypit packaging** | Titles, thumbnail concepts, distribution plans, video-from-script packages |
| **Omni** | RSS / podcast / non-YouTube adapted versions |

Always include `content_id` in filenames. Date in Central time.
