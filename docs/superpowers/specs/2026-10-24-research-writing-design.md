# Complete research and writing entrypoints

The owner requested completing the unfinished Master Research and System Glitch runners so the current batch can move before new data. Build on the existing Big One hub and preserve the owner's no-merge/deploy/delete/visibility-change limit and review before release.

Use a single shared Python implementation in The-Big-1 with thin private-repo adapters. Duplicating the hub in each lane would split claims and ledgers; replacing the existing runtime would discard working code. Preserve existing Psychology script-to-video commands and add a separate assignment-writing command.

Research consumes a dated, operator-supplied evidence packet and catalog snapshot. The packet must include source URLs, publication/observation dates, limitations and source-text files with hashes; copied text alone is not automatic verification of truth. Hermes receives those frozen files, produces daily signals, exactly ten ranked candidates, catalog comparison, market whitespace, and two source-linked assignments. Existing batch inputs are immutable on retry. No live trend or newly arrived data is mixed in automatically.

The hub invokes the real installed Hermes CLI with the existing isolated local-model transport. Writing-only preflight must not require render or speech tools. Research files must pass schema/source checks and real Drive upload/readback before RESEARCH_COMPLETE handoffs become claimable. Writing consumes an exclusive existing handoff, produces the complete lane package, enforces deterministic gates and a hash-bound Hermes writing review, and requires Drive readback before WRITING_COMPLETE. Repeats resume frozen output or reject conflicting inputs; completed assignments are not regenerated. Failures leave evidence and claims for explicit recovery.

A real Drive REST adapter uses a machine-owned OAuth access token, exact destination folder IDs, appProperties identity and upload/readback SHA256 comparisons. Credentials never enter Hermes prompts/environment. No publishing, inference/video pipeline changes, paid providers, background daemons or deployment.

Operational completion requires actual Hermes, local model, persistent shared paths and Drive credentials. Fixture tests establish the integration contract only. Missing prerequisites must fail with clear diagnostics and no false completion.
